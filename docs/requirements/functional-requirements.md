# FridgeMate 기능 요구사항 명세서

## 1. 문서 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | FridgeMate: OSS 기반 냉장고 식재료·유통기한 관리 서비스 |
| 관련 Issue | [Issue #4] User Class별 기능 요구사항 정의 |
| 입력 문서 | 운용개념서(CONOPS), User Class 정의서 |

| 문서 버전 | v0.1 (Sprint 2 초안) |

## 2. 목적과 작성규칙

본 문서는 운용개념서의 시나리오(SCN)와 User Class(UC)에서 도출한 시스템 기능을 정의한다. 각 요구사항은 "시스템은 ~해야 한다" 형식으로 쓰고, 고유 ID, 출처, 우선순위, 검증방법을 포함한다.

### 2.1 우선순위

| 등급 | 의미 |
|---|---|
| P0 | 서비스 목적에 꼭 필요한 MVP 필수 기능 |
| P1 | 핵심 사용을 돕는 기능으로 이번 범위에서 구현 권고 |
| P2 | 일정에 따라 후속 Sprint에서 구현 가능 |

### 2.2 검증방법

| 코드 | 방법 | 설명 |
|---|---|---|
| T | Test | 입력·조건·예상결과로 시험 |
| D | Demonstration | 실제 화면이나 사용 흐름 시연 |
| I | Inspection | 문서, 설정, 화면 구성 검토 |
| A | Analysis | 측정값 계산, 통계, 추적성 분석 |

## 12. 기능 요구사항 품질점검

- [ ] 모든 요구사항에 고유 ID, 출처, 우선순위, 검증방법이 있다.
- [ ] 한 문장에 하나의 기능만 담고 있다.
- [ ] "빠르게", "편리하게"처럼 측정할 수 없는 표현을 쓰지 않았다. (성능 수치는 비기능 요구사항에서 정의)
- [ ] 모든 시나리오(SCN-01~07)가 1개 이상의 요구사항으로 연결된다.
- [ ] Reviewer의 Approve를 받아 main에 Merge되었다.
