## 2. 목적

본 문서는 시스템이 기능을 얼마나 빠르고, 안정적이고, 안전하게 제공해야 하는지를 측정 가능한 수치로 정의한다. 목표값은 교육용 과제 기준이며 3주차 아키텍처 설계와 4주차 OSS 평가의 기준으로 사용한다. 우선순위(P0~P2)와 검증방법(T/D/I/A)은 기능 요구사항 명세서와 같다.

## 11. 비기능 요구사항 검토 체크리스트

- [ ] 모든 비기능 요구사항에 측정 가능한 수치와 측정조건이 있다.
- [ ] 프로젝트 정의서의 정량 목표(OBJ-01~04)가 비기능 요구사항으로 연결되었다.
- [ ] 보안·개인정보 요구사항이 운용정책과 일치한다.
- [ ] OSS 관련 요구사항(NFR-MNT)이 4주차 OSS 평가기준으로 사용 가능하다.
- [ ] Reviewer의 Approve를 받아 main에 Merge되었다.
