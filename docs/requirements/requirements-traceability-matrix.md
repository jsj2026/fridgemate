# FridgeMate 요구사항 추적표

## 1. 문서 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | FridgeMate: OSS 기반 냉장고 식재료·유통기한 관리 서비스 |
| 관련 Issue | [Issue #4], [Issue #5] |
| 입력 문서 | User Class 정의서, 운용개념서, 기능·비기능·인터페이스 요구사항 명세서 |
| 작성자 / Reviewer | 이정남 / 이지선 |
| 문서 버전 | v0.1 (Sprint 2 초안) |

## 2. 목적

이해관계자의 필요와 운용 시나리오가 기능·비기능·인터페이스 요구사항으로 빠짐없이 전환되었는지 확인한다. 3주차에는 각 요구사항을 아키텍처 구성요소와 OSS 평가항목에 추가로 연결한다.

## 3. 이해관계자 필요사항

| Need ID | 이해관계자 | 필요사항 |
|---|---|---|
| SN-01 | 1인 가구 사용자 | 식재료를 빠르고 쉽게 등록 |
| SN-02 | 1인 가구 사용자 | 유통기한이 지나기 전에 알림 받기 |
| SN-03 | 1인 가구 사용자 | 남은 재료로 만들 요리 추천 |
| SN-04 | 가족 공유 사용자 | 가족이 등록한 식재료를 함께 보고 중복 구매 방지 |
| SN-05 | 그룹 관리자 | 구성원 초대와 그룹 설정 관리 |
| SN-06 | 서비스 관리자 | 외부 연동과 알림 상태 확인, 장애 대응 |
| SN-07 | 전체 사용자 | 개인정보 보호와 안전한 접속 |

## 6. 프로젝트 목표-요구사항 추적

| 프로젝트 목표 | 검증 요구사항 |
|---|---|
| OBJ-01 등록 10초 이내 | NFR-PER-001 |
| OBJ-02 바코드 인식률 90% 이상 | NFR-REL-001 |
| OBJ-03 알림 누락 없이 발송 | NFR-REL-002, NFR-REL-003 |
| OBJ-04 목록 조회 2초 이내 | NFR-PER-003 |
| OBJ-05 OSS 후보 3개 이상 비교 | NFR-MNT-001~004 (4주차 평가기준) |

## 7. 비기능 요구사항의 아키텍처 영향 (3주차 입력)

| 품질속성 | 관련 요구사항 | 3주차 아키텍처 고려사항 |
|---|---|---|
| 성능 | NFR-PER-001~006 | 단말 내 바코드 인식, 상품 정보 캐시, 목록 API 최적화 |
| 신뢰성 | NFR-REL-001~005 | 알림 스케줄러, 외부 연동 실패 시 대체 흐름 |
| 가용성 | NFR-AVL-001~002 | 백업 방식, 호스팅 환경 선택 |
| 보안 | NFR-SEC-001~006 | 인증 방식, 그룹 단위 접근 제어, 비밀정보 관리 |
| 사용성 | NFR-USA-001~005 | 모바일 우선 화면, 자동완성, 상태 표시 |
| 호환성 | NFR-CMP-001~003 | PWA, Web Push 지원 범위, Container 배포 |
| 유지보수성 | NFR-MNT-001~005 | OSS 라이선스 관리, 외부 연동 교체 가능 구조 |

## 8. 3주차 OSS 후보 조사 대상 기능

| 기능 영역 | 관련 요구사항 | 조사할 OSS 유형 |
|---|---|---|
| 바코드 인식 | FR-011, IR-CAM-001~004 | 브라우저 바코드 인식 라이브러리 |
| 상품 정보 | FR-012, IR-PRD-001~005 | 공개 상품 DB, 데이터 API |
| 화면(PWA) | FR-020~FR-024, NFR-CMP-002 | 웹 Frontend 프레임워크, PWA 도구 |
| 백엔드·DB·인증 | FR-001~FR-010, IR-AUT-001~003 | Backend 프레임워크 또는 BaaS, DB |
| 알림 | FR-032~FR-038, IR-PSH-001~004 | Web Push 라이브러리, 알림 서버 |
| 레시피 | FR-039~FR-042, IR-RCP-001~003 | 공개 레시피 데이터 |

## 9. 추적성 완전성 점검

- [ ] 모든 시나리오가 1개 이상의 기능 요구사항과 연결된다.
- [ ] 모든 P0 기능 요구사항에 관련 비기능 요구사항 또는 검증방법이 있다.
- [ ] 프로젝트 정의서의 정량 목표가 모두 비기능 요구사항으로 검증된다.
- [ ] 외부개체가 모두 인터페이스 요구사항으로 연결된다.
- [ ] 연결되지 않은(고아) 요구사항이 없다.
