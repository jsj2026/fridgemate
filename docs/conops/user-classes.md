## 2. 목적

FridgeMate를 직접 또는 간접적으로 사용하는 사람을 User Class로 구분하고, 각 User Class의 목표, 사용 특성, 필요한 정보와 권한을 정의한다. 이 정의는 운용 시나리오와 요구사항 도출의 기준이 된다.

## 3. User Class 식별기준

| 기준 | 설명 |
|---|---|
| 사용 목적 | 시스템을 통해 얻고자 하는 가치가 다른가 |
| 사용 빈도 | 매일 사용하는가, 가끔 사용하는가 |
| 권한 범위 | 볼 수 있는 정보와 수정할 수 있는 정보가 다른가 |
| 숙련도 | 앱 사용에 익숙한 정도가 다른가 |

## 4. User Class 요약

|---|---|---|---|---|
| UC-01 | 1인 가구 사용자 | 혼자 쓰는 냉장고의 식재료 낭비 감소 | 매일 | 주 사용자 |
| UC-02 | 가족 공유 사용자 | 가족과 함께 쓰는 냉장고 정보 공유, 중복 구매 방지 | 매일 | 주 사용자 |

| UC-05 | Product Owner·교수자 | Backlog 우선순위 결정, 산출물 검토와 수용 판단 | Sprint마다 | 검토자 |

## 5. UC-01 1인 가구 사용자

### 5.1 역할과 목표
- 장 본 식재료를 빠르게 등록하고, 유통기한이 다가오면 알림을 받아 버리기 전에 소비한다.
- 남은 재료로 만들 수 있는 요리를 추천받는다.

### 5.2 사용자 특성
- 스마트폰 사용에 익숙하지만 입력이 번거로우면 쉽게 사용을 중단한다.
- 장보기를 주 1~2회 몰아서 하며, 한 번에 5~15개 품목을 등록한다.

### 5.3 필요 정보
- 보관 위치별 식재료 목록, 남은 유통기한(D-day), 임박 품목 요약, 추천 레시피

## 6. UC-02 가족 공유 사용자

### 6.1 역할과 목표
- 다른 가족이 등록한 식재료까지 함께 확인하여 중복 구매를 막는다.
- 꺼내 먹은 식재료를 소비 처리하여 목록을 최신 상태로 유지한다.

### 6.2 사용자 특성
- 연령과 앱 숙련도가 다양하다. 부모 세대는 단순한 화면을 선호한다.
- 같은 품목을 여러 명이 동시에 수정할 수 있다.

### 6.3 필요 정보
- 그룹 전체 식재료 목록, 등록자·수정자, 최근 변경 내역

## 7. UC-03 냉장고 그룹 관리자

### 7.1 역할과 목표
- 냉장고 그룹을 만들고 가족 구성원을 초대·제외한다.
- 알림 기준일(D-3, D-1 등)과 같은 그룹 공통 설정을 관리한다.

### 7.2 사용자 특성
- UC-01 또는 UC-02 사용자가 그룹을 만들면 관리자 역할을 함께 가진다.

## 8. UC-04 서비스 관리자

### 8.1 역할과 목표
- 서비스 상태, 외부 상품 정보 연동, 알림 발송 결과를 확인하고 장애에 대응한다.
- 잘못된 상품 정보 신고를 확인하고 수정한다.

### 8.2 사용자 특성
- 개발팀 구성원이 역할을 수행한다. 사용자 개인 식재료 내용은 운영 목적 외에 열람하지 않는다.

## 9. UC-05 Product Owner·교수자

### 9.1 역할과 목표
- Product Owner(팀장 이정남 겸임)는 Backlog 우선순위를 정하고 Sprint별 산출물의 수용 여부를 판단한다.
- 교수자는 최종 검토자로서 산출물을 검토하고 승인 또는 보완을 요청한다.

## 10. 간접 이해관계자

| 이해관계자 | 관계 | 고려사항 |
|---|---|---|

## 12. User Class 기반 설계원칙

- 등록은 바코드 스캔을 기본으로 하고, 3번 이내의 터치로 끝낼 수 있게 한다.
- 숙련도가 낮은 가족 사용자를 고려해 화면 용어를 쉽게 쓰고, 상태를 색상과 글자로 함께 표시한다.
- 서비스 관리자는 사용자의 식재료 기록을 운영 목적 외에는 보지 않는다.
